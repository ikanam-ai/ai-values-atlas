# Scope and inclusion rules

## Core

Include as `core` when a work operationalizes at least one of the following:

- a value, value system, value priority, or value representation of an AI system;
- moral or cultural values as a structured construct;
- value identification in text or internal representations;
- consistency between stated, chosen, generated, or enacted values;
- alignment or steering toward explicit values, principles, rights, or duties;
- aggregation or pluralistic representation of human values for AI.

## Adjacent

Include as `adjacent` when the main construct is preference, opinion, norm,
personality, safety, culture, or personalization, but the methods or artifacts are
directly reusable for value research.

## Background

Foundational axiology, psychometrics, social choice, and measurement theory can be
included as `background` when a core paper relies on it.

## Exclude

- “value” meaning a numerical value, business value, or model value function with
  no normative/preference interpretation;
- generic RLHF, safety, or bias papers with no explicit connection to values,
  norms, moral judgments, preferences, or pluralism;
- generic personality work unless it contributes a measurement or validation
  method used in value research;
- secondary blogs when a primary publication is available.

## Catalog harvesting

Harvesting is intentionally broader than verified inclusion. Links from selected
sections enter the discovery queue with source and section provenance. Curators
then assign `core`, `adjacent`, `background`, or `excluded`.
